របៀបកែធៀបអញ្ជើញ
===================
index.html  = អត្ថបទ និងរចនាសម្ព័ន្ធ (ឈ្មោះ កាលបរិច្ឆេទ ទីកន្លែង កម្មវិធីពិធី)
style.css   = ពណ៌ ស៊ុម ទំហំអក្សរ ផ្ទៃខាងក្រោយ និងរចនាបថបេះដូងធ្លាក់ (#hearts, .hrt)
script.js   = ចលនាបើកប្រអប់ ការរាប់ថយក្រោយ បេះដូងធ្លាក់ និង QR ABA
images/     = រូបថត (ប្តូរឈ្មោះឯកសារដដែល ដើម្បីជំនួសរូប)

កែអ្វី នៅឯណា:
- ម៉ោង/ថ្ងៃរាប់ថយក្រោយ : script.js រកពាក្យ new Date("2026-12-11T17:30:00+07:00")
- បេះដូងធ្លាក់           : script.js ក្នុង startHearts() - ប្តូរ 650 (ល្បឿនកើត), cols (ពណ៌), r(11,24) (ទំហំ)
- ទីកន្លែង               : index.html រកពាក្យ [ឈ្មោះទីកន្លែង] និង [អាសយដ្ឋាន]
- តំណ Google Maps        : index.html រកពាក្យ id="mapLink" ប្តូរ href
- កម្មវិធីពិធី            : index.html រកពាក្យ class="prog"
- QR ABA                 : script.js រកពាក្យ text:"0002010102..."
- ពណ៌                    : style.css ផ្នែកខាងលើ :root{--brown ... --rose ...}

សម្គាល់: ត្រូវការអ៊ីនធឺណិតដើម្បីឲ្យពុម្ពអក្សរខ្មែរ (Google Fonts) និង QR (cdnjs) ដំណើរការ។
បើកដោយចុចពីរដងលើ index.html។ ដើម្បីបង្ហោះលើអ៊ីនធឺណិត អាចប្រើ Netlify Drop ឬ GitHub Pages។
